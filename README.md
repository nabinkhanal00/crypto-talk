# From Scytale to Signal

An interactive talk on the basics of cryptography (Part 1, about 60 minutes): ancient ciphers, the Enigma machine, perfect secrecy and end-to-end encryption.

Open `index.html`, or view it on GitHub Pages. Press → or Space to advance, N for speaker notes, T to switch light/dark.

`tests/` holds the in-browser checks: open the deck, paste `tests/p1-test.js` into the console and run `await runP1Tests()`.
